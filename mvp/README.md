# 🌧️ Jakarta Flood Early Warning System – MVP Guide

## ⚠️ Note: Retraining Across Python / scikit-learn Environments

If the pre-trained `.joblib` bundles in `models/` were serialized under a different `scikit-learn` version than your local environment, retrain them once locally using `retrain_combined.py`.

---

## Quick Start (Step-by-Step)

### Step 1 — Install Dependencies
```bash
pip install -r mvp/requirements_mvp.txt
```

### Step 2 — Retrain Models (One-Time Setup)
```bash
python sourcecode/retrain_combined.py
```
This script will:
- Load `dataset/jakarta_flood_combined.xlsx`
- Engineer cyclical time features, multi-hour lag features, and rolling hydro-meteorological aggregations
- Train both models (`HistGradientBoostingClassifier` + `HistGradientBoostingRegressor`)
- Save artifacts automatically to `models/flood_classifier.joblib` and `models/flood_depth_regressor.joblib`

Estimated runtime: **2–5 minutes** depending on hardware.

### Step 3 — Launch the Web App
```bash
streamlit run mvp/app_streamlit.py
```

### Step 4 — Upload Artifacts in Browser
In the Streamlit sidebar, upload:
1. `models/flood_classifier.joblib`
2. `models/flood_depth_regressor.joblib`
3. `dataset/jakarta_flood_combined.xlsx`

Select a Municipality & Sub-district to inspect 6-hour flood forecasts.
